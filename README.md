# MiniMax H3 Japanese Prompt Skill

MiniMax H3向けの動画プロンプトを、入力素材・尺・撮影意図・音声まで整理して作成するCodex Skillです。

MiniMax公式のプロンプト構造を基準に、テキスト生成、先頭／最終フレーム、画像・動画・音声参照に対応します。日本語リップシンク向けの発話表記と、シネマトグラフィー、カメラ、レンズの選択ガイドも含みます。

## できること

- 入力素材からMiniMax H3のモードを判定
- 映像と音声を再生順に整理した、コピー可能なプロンプトを作成
- 参照画像・動画・音声の役割、保持範囲、話者を明示
- ショットサイズ、アングル、カメラ移動、レンズ、照明、構図を撮影意図に合わせて選択
- 画角、遠近感、被写界深度、フォーカス、ズーム、カメラ移動の混同や矛盾を検査
- 日本語のセリフ、ナレーション、歌詞をリップシンク向けに整形
- MiniMax APIやローカル環境向けの構造化形式と、一般的なプロンプト欄向けの自然文形式を使い分け
- プロンプトの新規作成、修正、翻訳、短縮、失敗原因の診断に対応

## 対応モード

| モード | 入力 | 主な用途 |
| --- | --- | --- |
| `T2VA` | テキストのみ | 映像、動作、カメラ、セリフ、効果音、音楽を一から設計 |
| `I2VA` | 先頭フレーム | 最初の画像を固定し、その後の動きと終着状態を設計 |
| `FL2VA` | 先頭・最終フレーム | 2枚の画像をつなぐ連続的で無理のない変化を設計 |
| `L2VA` | 最終フレーム | 指定された最終画像へ自然に到達する開始状態と動きを設計 |
| `Ref2VA` | 参照画像・動画・音声 | 人物、物体、画風、構図、動き、カメラ、編集、声、音響などを参照 |

人物やスタイルを示す画像は、必ずしも先頭・最終フレームではありません。完全なキーフレームとして使う素材と、特徴だけを参照する素材を区別して扱います。

## インストール

### いちばん簡単：チャットで依頼する

Codexのチャット欄に、次の文章をそのまま貼り付けて送信します。

```text
次のGitHubリポジトリから `minimax-h3-prompt` Skillをインストールしてください。
https://github.com/4n5AI/MiniMaxH3-japanese-prompt-skill
```

短く依頼する場合は、リポジトリURLと「このSkillをインストールして」だけでも構いません。Skill名まで書くと、対象をより確実に指定できます。

```text
https://github.com/4n5AI/MiniMaxH3-japanese-prompt-skill
このSkillをインストールして。
```

### CLIからインストールする

```bash
npx skills add https://github.com/4n5AI/MiniMaxH3-japanese-prompt-skill --skill minimax-h3-prompt
```

Skill名は `minimax-h3-prompt` です。暗黙呼び出しの設定（`allow_implicit_invocation: true`）が有効なので、Codexは内容が一致するMiniMax H3の依頼でこのSkillを自動選択できます。明示的に使う場合は `$minimax-h3-prompt` を指定してください。

MiniMax H3の依頼で必ず毎回使用させたい場合は、プロジェクトまたはユーザーの `AGENTS.md` に次のような規則を追加します。

```markdown
MiniMax H3のプロンプトを作成、修正、翻訳、短縮、改善、診断するときは、
会話の続きやセリフだけの修正も含め、必ず毎回 `minimax-h3-prompt` Skillを使用する。
```

## 使い方

自然な日本語で目的と素材を伝えます。最低限、被写体、起こること、利用する参照素材が分かれば、不足項目は必要に応じて補完されます。

```text
$minimax-h3-prompt
8秒、16:9。夕方の駅で女性が電車を見送り、最後にカメラを見る。
静かな実写。セリフは「またAIで会おう」。音楽なし。
```

```text
この画像をMiniMax H3の先頭フレームとして使ってください。
人物の服とロゴを変えず、カメラがゆっくり横へ移動して店内を見せるプロンプトにしてください。
```

```text
参照動画はカメラワークだけ、参照音声は声質だけを使ってください。
元動画の人物、背景、セリフは引き継がないでください。
```

継続依頼では、既に決めたモード、尺、アスペクト比、参照素材、人物設定を引き継ぎます。変更したい項目だけを伝えれば修正できます。

## 出力形式

### 構造化形式

MiniMax API、ローカル／オープンウェイト環境、複雑な参照指定では、公式ガイドに沿った構造化プロンプトを既定で使用します。

- `T2VA`、`I2VA`、`FL2VA`、`L2VA`：映像記述、全体音響、非劇中音楽の3フィールド
- `Ref2VA`：参照定義、要約、保持分析、詳細記述、全体音響、非劇中音楽の6セクション

これらの名称はプロンプト本文を整理するための構造です。すべてのサービスで同名のAPIパラメーターが必要という意味ではありません。

### 自然文形式

Hailuo AIなどの簡潔なプロンプト欄を明示された場合は、同じタイムライン、参照役割、カメラ、発話、音響の判断を保ったまま自然文にまとめます。素材ラベルは利用画面に表示される `画像1`、`Image 1`、`@image1` などに合わせ、複数の命名方式を混在させません。

## 日本語リップシンク

実際に発話・歌唱する日本語だけに、次の規則を適用します。

| 規則 | 変換例 |
| --- | --- |
| AIが読みにくい難しい漢字はひらがなにする | `今日の進捗` → `きょうのしんちょく` |
| 数値は算用数字にする | `二千年、百九十二回` → `2,000年、192回` |
| 発話する英語はカタカナにする | `AI、OpenAI` → `エーアイ、オープンエーアイ` |

URL、ファイル名、API識別子、参照タグなど、発話しない文字列は変更しません。字幕、看板、ロゴなどの表示文字列もそのまま保持します。同じ内容を画面に表示しながら発話する場合は、表示用と発話用を分離します。

```text
表示文字: "AI 二千年"
発話: <d>[Japanese] エーアイ、2,000年。</d>
```

指定されたセリフを尺に収めるために無断で言い換えることはありません。収まらない場合は、短縮案、尺の延長、発話の分割を提案します。

## シネマトグラフィー

撮影技法は、次の7軸から必要なものだけを選びます。

| 軸 | 主な判断 |
| --- | --- |
| ショットサイズ | 情報、表情、身ぶり、全身、場所のどれを見せるか |
| アングル | 目線の高さ、上下関係、主観、俯瞰、緊張感 |
| カメラ移動 | 静止、パン、チルト、ドリー、追跡、旋回、クレーン、ドローンなど |
| レンズ・フォーカス | 広角、標準、望遠、マクロ、被写界深度、ラックフォーカスなど |
| 時間表現 | スローモーション、スピードランプ、タイムラプス、長回しなど |
| 照明 | 光源、方向、硬さ、色、被写体との分離 |
| 構図 | 三分割、対称、誘導線、額縁、余白、前景レイヤーなど |

技法名を並べるのではなく、「何を見せたいか」「カメラがどこからどこへ動くか」「最後にどの構図へ着地するか」を文章化します。ドリーズームのような協調動作は許容し、固定カメラと手持ち旋回など両立しない指定は避けます。

## カメラとレンズ

レンズは機材名ではなく、画面に生じる効果と使い所から選びます。

| 選択 | 向いている場面 | 主な効果 |
| --- | --- | --- |
| 広角 | 室内、風景、建築、被写体と環境を同時に見せる場面 | 広い範囲、強い奥行き、前景と背景の距離感 |
| 標準 | 日常、会話、インタビュー、自然な人物描写 | 誇張を抑えた距離感と背景情報 |
| 望遠 | ポートレート、遠方の被写体、スポーツ、野生動物 | 狭い画角、背景整理、遠景が重なって見える構図 |
| マクロ／近接 | 商品、文字、質感、細かな動き | 小さな対象の拡大と焦点範囲の明示 |
| フィッシュアイ | のぞき穴、極端な主観表現 | 意図的な周辺湾曲 |
| アナモフィック風 | 横方向の広がりや特徴的なハイライトが必要な場面 | 楕円形ボケや控えめな水平フレア |

焦点距離を指定する場合は、原則として35mm判換算の表現上の目安として扱います。遠近感はカメラ位置、被写界深度は焦点距離だけでなく絞り・撮影距離・センサーなどにも左右されるため、必要な見え方を文章でも指定します。MiniMax H3が実在のカメラやレンズを物理的に再現することを保証するものではありません。

## 対象範囲と注意点

- MiniMax H3専用です。MiniMax Hailuo 2.xや他社モデルへ自動適用しません。
- Hailuo AIや第三者サービスでは、利用可能なモデル、入力素材、UIラベル、制限が異なる場合があります。
- APIのモデル名、入力上限、尺、解像度など変更され得る仕様は、利用時点のMiniMax公式資料を優先してください。
- プロンプトの矛盾を減らすためのSkillであり、生成結果の完全な再現、発音、リップシンク、カメラワークを保証するものではありません。
- 実在人物の容姿や声を参照する場合、権利や許可があることをSkillが推測・保証することはありません。

参照した公式資料と第三者資料、それぞれの扱いは [sources.md](skills/minimax-h3-prompt/references/sources.md) にまとめています。
