# MiniMax H3 Japanese Prompt Skill

MiniMax H3向けの動画プロンプトを、日本語話者が再利用しやすい形で作成するCodex Skillです。公式のH3プロンプト構造を基準に、テキスト、首フレーム、首尾フレーム、尾フレーム、オムニリファレンスの各モードを扱います。

## インストール

```bash
npx skills add https://github.com/4n5AI/MiniMaxH3-japanese-prompt-skill --skill minimax-h3-prompt
```

## 主な特徴

- MiniMax H3の入力モードに応じたプロンプト設計
- 参照画像・動画・音声の役割とラベルの明示
- ショット、カメラ、動作、音響を再生順に整理
- 日本語リップシンク向けの読みやすい発話表記
- Hailuo AI、MiniMax API、一般的なH3対応画面向けの出力調整

## 情報源

公式資料を優先し、第三者ガイドとコミュニティ事例は補助的に参照しています。詳細なURLと採用方針はSkill内の `references/sources.md` に記載しています。
